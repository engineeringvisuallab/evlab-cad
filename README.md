# EVLab CAD
Browser-based 2D CAD (Engineering Visual Lab). No build step, no dependencies.
**Status: Milestone 7 of 8.** Run: `python3 -m http.server 8000` in this folder, open http://localhost:8000 (ES modules need http, not file://). Tests: `node tests/viewport.test.mjs && node tests/entity.test.mjs && node tests/precision.test.mjs && node tests/modify.test.mjs && node tests/io.test.mjs && node tests/dxf.test.mjs && node tests/layout.test.mjs`.
Functional: canvas, adaptive major/minor grid, X/Y axes, wheel zoom at cursor, pan (Pan button, middle mouse, or Space+drag), zoom in/out/reset, F7 grid toggle, live world coordinates, units label.
Not built yet: everything else in the spec (drawing tools, layers, command line, DXF…). Zoom extents currently resets the view because the drawing is empty.
Deploy: push to a public repo, Settings → Pages → Deploy from branch → main / (root). Paths are relative; `.nojekyll` included.

Milestone 2 adds: line, polyline, rectangle, circle, arc (centre, start, end); click/shift/window/crossing selection (box test uses bounding boxes); properties panel with editable geometry (validated, rejects invalid values); Delete key/button. Grips are display-only (not draggable yet). Delete cannot be undone until Milestone 4.

Milestone 3 adds: coordinate entry (`100,200`, `@50,0`, `@100<45`, direct distance), object snaps (endpoint, midpoint, center, intersection of line/polyline segments, perpendicular, nearest), grid snap (F9), ortho (F8), OSNAP toggle (F3), layers (create, delete-if-empty, rename, current, colour, visible/lock/freeze, assign, isolate), and a command line (LINE, PLINE, CIRCLE, ARC, REC, ERASE, DIST, LAYER, ZOOM, PAN, ORTHO, SNAP, OSNAP, HELP; Enter repeats/finishes, Esc cancels, Up/Down history).
Not built: polar tracking, dynamic input, circle/arc intersection snaps, line type/weight UI (stored in the model only), plot flag UI, paper space. Other spec commands answer "planned for Milestone N".

Milestone 4 adds: undo/redo (Ctrl+Z / Ctrl+Y, snapshot-based; every command is a transaction that rolls back on error); select objects first, then MOVE, COPY, ROTATE (click or type degrees), SCALE (type factor), MIRROR (keeps originals), ARRAY rows cols rowSpacing colSpacing, EXPLODE (polylines), JOIN (lines/open polylines), AREA; OFFSET n (lines, circles, arcs), TRIM/EXTEND (lines against line/polyline edges), FILLET r / CHAMFER d (two lines); DIST and AREA measurements; linear, aligned, radius and diameter dimensions (values always computed; radius/diameter and line-referenced aligned dims update when the object changes; point-picked dims are fixed points).
Not built: STRETCH, BREAK, angular dims, leaders, text/dimension style editor (fixed default style: 2 decimals, scale 1), polyline offset, trimming arcs/circles, polar array. Dimension window-selection tests each dimension line separately.

Milestone 5 adds: versioned JSON project format (`format: evlab-cad`, `version: 1`) saving geometry, entity IDs, layers, units, dimension style, current layer and metadata; New / Open / Save (Ctrl+S) / Save As, also via commands NEW, OPEN, SAVE, SAVEAS. Chromium browsers write straight to the chosen file (File System Access API); other browsers download a copy instead, so repeated Save creates a new download. Files are fully validated before they replace the open drawing; invalid, damaged or newer-version files are rejected with a reason. Autosave runs 1.5 s after each change to browser storage, one key per project, and is removed after a successful save. After a crash or refresh the newest unsaved drawing is offered for recovery on next load; declining asks before deleting it. The tab warns before closing with unsaved changes.
Not saved: undo history, selection, view position, text/dimension style editing (not built yet). Block definitions arrive in Milestone 7. Autosave depends on browser storage (about 5 MB); a failure is reported in the command line.

Milestone 6 adds DXF (ASCII) import and export. File menu: Import DXF… / Export DXF…, toolbar Export DXF, commands DXFIN / DXFOUT. Export writes DXF R2000 (AC1015): LINE, CIRCLE, ARC, LWPOLYLINE, layers (name, colour as ACI + true colour, on/off, frozen, locked, plot flag, lineweight), entity colours, and units ($INSUNITS mm/m). Dimensions are written as plain lines, arrowheads and TEXT (they will not stay associative elsewhere). Import reads LINE, CIRCLE, ARC, LWPOLYLINE and old-style POLYLINE/VERTEX, plus layer table, ACI/true colours, lineweights, units. Import opens as a new, unsaved project after confirming discard of the current one.
Unsupported and reported on import (never silently dropped): POINT, ELLIPSE, TEXT/MTEXT, DIMENSION, SPLINE, INSERT/blocks, HATCH, bulge (arc) polyline segments, 3D polylines/meshes, entities with a non-default extrusion direction, line type names (all imported as Continuous), and Z coordinates (dropped, counted). POINT, ELLIPSE and text need entity types we do not have yet (text arrives in Milestone 7). DWG is not supported; export DXF from your CAD software.
Verification honesty: round trips are tested with EVLab's own importer plus hand-written DXF samples in the style of other CAD programs. The exporter has NOT been checked against AutoCAD, LibreCAD or another independent reader; open an exported file in one and report problems.

Milestone 7 adds:
- Text: TEXT/T and MTEXT/MT (click a point, type the text; `\\n` starts a new line; `TEXT 5` sets the height). One text entity serves both; editable in the properties panel; saved in JSON; exported to DXF as TEXT or MTEXT and imported from both (MTEXT formatting is simplified).
- Blocks: select objects, `BLOCK name`, click the base point. Insert from the Blocks panel or `INSERT name [scale] [rotation]`; position, scale and rotation are editable in the properties panel; EXPLODE turns a reference back into geometry. `BLOCKS` lists them. "Add civil symbols" loads editable North arrow, Manhole, Valve, Tree and Survey point blocks. Block members take the reference's layer. Blocks cannot contain dimensions or other blocks, and block references cannot be mirrored (explode first).
- Layout (paper space): Layout button / `LAYOUT` / `MODEL`. Sheets A4/A3/A2/A1, landscape or portrait, border, title block (project, title, drawing no., revision, scale), optional north arrow, one viewport showing model space at a chosen scale 1:N (model units mm or m are respected). "Fit model to viewport" picks the scale and centre from what will print. Plots layers that are visible, thawed and plot-enabled, in black, with line weights from layers in millimetres.
- Export: PDF (`PDF`, vector, A-series page, built-in Helvetica) and SVG (`SVG`). Preview, PDF and SVG are produced from one sheet description, so they show the same geometry.
Not built: block attributes, block definitions in DXF (references are exported as exploded geometry), multiple layouts or viewports, viewport layer overrides, PNG and CSV export, plot styles/colours, text styles/fonts (Latin-1 only in PDF; the diameter sign prints as Ø). Text width is approximate (0.55–0.6 × height per character), which affects selection boxes and centring slightly.
Verification honesty: the PDF's structure (header, xref offsets, stream length, page size, operator counts) is checked by tests, but it has not been opened in a PDF viewer or printed; check a real export before relying on it. Text and DXF output has the same caveat as Milestone 6.
